# Suhyeon Lee Personal Website

Static GitHub Pages site for `https://hyn2028.github.io/`.

## Edit Before Publishing

- Replace `assets/profile.jpg` if you want a different photo. The page falls back to `assets/profile-placeholder.svg` if this file is ever removed.
- Update `assets/Suhyeon_Lee_CV.pdf` whenever the CV is revised.
- Add new entries to the News/Publications sections in `index.html` as they come up.

## Publish

```bash
git add .
git commit -m "Update personal website"
git push
```
